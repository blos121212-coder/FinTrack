# FinTrack — финансовый учёт предприятия

Учебное Full-stack приложение. Python 3.10+, SQLite, HTML/CSS/JavaScript. Дополнительные библиотеки не требуются.

## Запуск
Скачайте исходники (Code → Download ZIP), распакуйте архив, установите Python 3.10+, запустите `start.bat` на Windows или `python3 server.py` на Linux/macOS. Откройте http://127.0.0.1:8000. Демо: `demo` / `Demo2026!`. База создаётся автоматически. Остановка: Ctrl+C.

## Архитектура
Браузер → HTTP JSON API → Python → SQLite. Таблицы users, sessions, ops. Связи users 1:N sessions и users 1:N ops. Суммы хранятся целым числом копеек. Пароли защищены PBKDF2-HMAC-SHA256 с солью, сессии используют HttpOnly/SameSite cookie, SQL-запросы параметризованы. Пользователи видят только свои операции. Администратор также видит список аккаунтов. CSV, фильтры, диаграммы, CRUD, регистрация.

## Ограничения
Локальный учебный прототип с условными демонстрационными данными; не проводит реальные платежи. Для публичного размещения нужны HTTPS, удаление демонстрационного аккаунта, ограничение попыток входа, аудит, резервное копирование, нагрузочные испытания и проверка регуляторных требований.
